## Подтверждённые условия API

- Все шесть CRUD-эндпоинтов и штатные коды 200/201/204.
- Ответ 400 на ошибки типов, диапазонов, длин, неизвестные поля и некорректный JSON.
- Ответ 404 на отсутствующую запись, ответ 500 на контролируемый сбой базы.
- Формат ошибок `error`/`details` и продолжение работы после ошибочного запроса.
- Полная замена PUT и частичная замена PATCH.
- Сохранение записи и избранного после закрытия и повторного создания сервера.
- Неповторяемость ID после удаления и перезапуска.
- Применение SQL-миграции и безопасное повторное применение.
- CORS OPTIONS, заголовки на фактическом запросе и отсутствие разрешения для чужого источника.
- Строгая проверка boolean, отсутствие смешения bool с integer.
- Безопасная передача SQL/HTML-строк как данных.
- Демонстрационное заполнение без перезаписи существующих данных.

Тесты выполнялись с временными SQLite-файлами; пользовательская база не затрагивалась.
